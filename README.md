# VoiceTranslate

VoiceTranslate is an offline desktop speech translation system with three processes: enrollment, outgoing translation, and incoming captions.

## Quick Start
1. Create and activate a Python 3.11 virtual environment.
2. Install dependencies with `pip install -e ".[dev]"`.
3. Copy `.env.example` to `.env`.
4. Run `make run`.

See `docs/setup.md` for full setup.
